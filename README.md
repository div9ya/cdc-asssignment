# 🔥 Overview

This repository contains a collection of **Data Structures and Algorithms (DSA)** assignments and practice problems implemented in **Java**.

The repository is organized topic-wise and includes solutions for various important DSA concepts such as:

- Arrays
- Sorting
- Binary Trees
- Binary Search Trees
- Linked Lists
- HashMaps
- Recursion
- Strings
- Matrix Problems
- Sliding Window Technique
- Backtracking Problems

The project is designed for:
- 📘 Learning DSA concepts
- 💻 Coding practice
- 🧠 Interview preparation
- 🚀 Improving problem-solving skills
